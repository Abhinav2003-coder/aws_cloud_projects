# 🏋️‍♂️ Serverless Gym Membership System

A cloud-native web application for managing gym memberships, user profiles, and active plans without managing any servers.

## 🚀 Tech Stack & Services
* **Hosting & CDN:** Amazon S3 & Amazon CloudFront
* **Authentication:** Amazon Cognito
* **API Layer:** Amazon API Gateway
* **Compute:** AWS Lambda
* **Database:** Amazon DynamoDB

## 📂 Project Structure
* `frontend/` - HTML, CSS, and JS files
* `backend/` - Python/Node.js Lambda functions (Member registration & status check)

# 📝 Serverless Student Attendance Management System

A full-stack serverless web application built on AWS to track and manage student attendance securely.

## 🚀 Tech Stack & Services
* **Frontend:** HTML, JavaScript (Hosted on Amazon S3)
* **Authentication:** Amazon Cognito (User Sign-up & Login)
* **API Layer:** Amazon API Gateway
* **Compute:** AWS Lambda
* **Database:** Amazon DynamoDB

## 📂 Project Structure
* `frontend/` - Web interface & authentication logic
* `backend/` - AWS Lambda backend functions
